# Pack 3721 – Scouting for Food

This repo holds the maps and tools for Pack 3721's Scouting for Food walk.

- **Day-of tracker (in progress):** a phone map with a GPS dot and tap-to-text the dispatcher, in [`app/`](app/) on GitHub Pages. See [PLAN.md](PLAN.md).
- **2026 map pack:** built by the scripts in [`planner/`](planner/). The printed PDFs are in the pack's Google Drive.
- **How the maps were made:** [docs/how-the-maps-were-made.md](docs/how-the-maps-were-made.md).

Map data comes from:
- St. Louis County GIS Service Center (address points and street centerlines)
- Microsoft Global ML Building Footprints (CDLA-Permissive-2.0)
- the pack's own boundary map
