# Social card

`app/social-card.png` (1200×630) is the picture shown when the map link is shared. `card.html` lays it out. To remake it:

1. Take two Pixel 7-sized screenshots of the app, `map.png` (a den map with a target) and `card.png` (the same with the target's card open), using example data such as "Wolf A" and no real phone numbers.
2. Put them next to `card.html` with `icon.png` (a copy of `app/icons/icon-192.png`).
3. Open `card.html` in a 1200×630 browser window, screenshot it, and save it as `app/social-card.png`.
