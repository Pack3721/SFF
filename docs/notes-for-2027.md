# Notes for 2027 Week 1

Written down after the 2026 Week 1 walk (bags, Sat Nov 14, 2026).

**Overall:** Week 1 worked really, really well.

## Texting and done marks

- Parents text the dispatcher from the app when a segment is done. But not everyone in a group texts, even when more than one phone in the group is tracking the same segments.
- Right now Done always opens a text, on every phone. Instead, ask each phone whether it's the group's texter. Only the texter's Done sends a text; the others just mark the segment done.

## Picking the next segment

- After finishing the target segment, the app should use GPS to switch the target to the nearest unfinished segment. Only when GPS is available; without it, leave the target empty (as now).
- Swiping to the next target was a lot sometimes. The swipe goes in segment-number order, and the arrows on the map are only suggestions, not necessarily the best way on the ground.
